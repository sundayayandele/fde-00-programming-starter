# C4 views

## Level 1: System context

```mermaid
C4Context
  title Complaint-data ingestion: system context
  Person(analyst, "Complaints analyst", "Reads summaries and searches complaints")
  Person(eng, "ML engineer (fde-01, fde-04)", "Uses the stored complaints to train models")
  System(sys, "Complaint-data ingestion service", "Scheduled ingest job + report API")
  System_Ext(cfpb, "CFPB Consumer Complaint Database", "Public search API and bulk CSV")
  Rel(sys, cfpb, "Pulls complaints daily", "HTTPS")
  Rel(analyst, sys, "Reads reports", "HTTPS / JSON")

```

## Level 2: Containers

```mermaid
C4Container
  title Complaint-data ingestion: containers
  Person(analyst, "Analyst")
  System_Ext(cfpb, "CFPB API / CSV")
  Container(job, "Ingest job", "Python CLI complaints-ingest", "Fetch, clean, mask PII, validate, upsert, quality report")
  Container(api, "Report API", "FastAPI, uvicorn", "Health, metrics, summary, search, run log")
  ContainerDb(db, "Complaints database", "SQLite locally; Postgres 16 elsewhere", "complaints, ingest_runs")
  Container(sched, "Scheduler", "CronJob / EventBridge Scheduler / Container Apps Job / Cloud Scheduler", "Starts the job daily")
  Container(prom, "Prometheus + Grafana", "Monitoring", "Scrapes /metrics/, alerts on stale ingest")
  Rel(sched, job, "Starts")
  Rel(job, cfpb, "HTTPS")
  Rel(job, db, "Upserts")
  Rel(api, db, "Reads")
  Rel(analyst, api, "HTTPS")
  Rel(prom, api, "Scrapes")
```

## Level 3: Components

| Component | Module | Responsibility |
| --- | --- | --- |
| Canonical schema | `schema.py` | `Complaint` model, field maps for API and CSV, required fields |
| Cleaning | `clean.py` | Text, boolean and date parsing; PII masking; row → `Complaint` or rejection reason |
| Source readers | `cfpb.py` | API paging with retries; streamed CSV |
| Storage | `store.py` | Tables, portable upsert, run log |
| Quality | `quality.py` | Per-run counters and report |
| Reports | `report.py` | Aggregations shared by CLI and API |
| Pipeline and CLI | `pipeline.py`, `cli.py` | Batching, timing, commands |
| HTTP layer | `app/main.py` | Routes, validation, metrics, data-freshness gauges |
