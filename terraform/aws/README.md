# AWS lab stack

ECR; ECS Fargate running the report API (0.25 vCPU, 512 MB, one task, public IP, no load
balancer); a second task definition for the ingest job, started daily by **EventBridge
Scheduler**; **RDS for PostgreSQL 16** (`db.t4g.micro`, 20 GB gp3, private, encrypted);
Secrets Manager holding `DATABASE_URL`; CloudWatch Logs; and a monthly budget with alerts at
50, 80 and 100 percent of USD 50.

```bash
make tf-aws-init
terraform -chdir=terraform/aws plan -out=tfplan -var alert_email=you@example.com \
  -var allowed_cidr=$(curl -s ifconfig.me)/32
make tf-aws-apply                                  # RDS takes about 5-10 minutes

# Push the image (the API service and the scheduled task both use it), then roll the service
REPO=$(terraform -chdir=terraform/aws output -raw ecr_repository_url)
aws ecr get-login-password | docker login --username AWS --password-stdin ${REPO%/*}
docker tag fde-00-programming:local $REPO:1.0.0 && docker push $REPO:1.0.0
aws ecs update-service --cluster fde-00-programming --service fde-00-programming --force-new-deployment

# Load data now instead of waiting for 06:15 UTC, then smoke test
eval "$(terraform -chdir=terraform/aws output -raw run_ingest_now)"
IP=$(eval "$(terraform -chdir=terraform/aws output -raw find_public_ip)")
python scripts/smoke_test.py --base-url http://$IP:8000
curl -s http://$IP:8000/api/v1/runs | python -m json.tool

make tf-aws-destroy
```

Notes:

- The database password is generated by Terraform (`random_password`) and lives in state and in
  Secrets Manager. Keep state private; never commit it.
- The ingest task needs outbound internet for the CFPB API; it gets a public IP in the default VPC.
- Build for `linux/amd64` on Apple silicon: `docker build --platform linux/amd64 ...`.
- Estimated monthly cost while running: see `docs/COST-TCO.md`. Set `desired_count=0` between
  labs to stop the API task; RDS keeps charging until you destroy.
